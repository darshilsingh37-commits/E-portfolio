# Portfolio (Enhanced)

## How to run
- **Option 1 (quick):** open `index.html` in your browser.
- **Option 2 (recommended):** run a local server in this folder:
  - `python -m http.server 5173`
  - then open: `http://localhost:5173`

## Background video
The background video file is here:
`assets/bg-video.mp4`

You can replace it with your own **MP4** (keep the same name) for a more personal/professional look.
